# Tetris Advanced Game

## Overview
This project is a complete C++ console-based Tetris game developed using object-oriented programming principles. It includes falling tetromino blocks, rotation, scoring, difficulty levels, high-score tracking, and save/load support.

## Project Features
- Classic falling block gameplay
- Left, right, down, and rotation controls
- Line clearing and score management
- Game-over detection
- High score tracking
- Difficulty selection
- Theme selection
- Save and continue game functionality
- Console-based user interface

## Controls
- A / D: Move left / right
- W: Rotate block
- S: Move downward
- H: Hold current piece

## Technical Details
- Language: C++
- Platform: Windows Console
- Dependencies: `windows.h`, `conio.h`
- File: `main.cpp`

## Notes
This project is designed for a Windows console environment and includes sound effects and colored console output for a more interactive gameplay experience.

## Project Summary
This game demonstrates practical implementation of game logic, board management, object handling, and console UI design in C++.
